Base URL: the API origin (the SPA's origin in production). All bodies are JSON; the REST
listener accepts request bodies up to 2 MB. Auth endpoints under `/v1/auth` are listed in
[Authentication](/docs/backend/authentication).

## Conventions

- **Auth**: `Authorization: Bearer <access_token>` unless marked public.
- **Role**: the minimum organization role (`member` < `admin` < `owner`); "member" means
  any member of the owning organization. See [Authorization](/docs/backend/authorization).
- **Lists** take `offset` (default 0), `limit` (default 20, max 100), `order_by` and
  `order` (`asc`/`desc`), and answer `{ data: [...], metadata: { total, offset, limit } }`.
- **Errors** answer `{ message }`. Validation failures are `422` with per-field messages;
  malformed JSON is `400`; missing or invalid token `401`; membership or role `403`;
  unknown records `404`.

## Organizations

| Method | Path                                                 | Role   | Body                                                 |
| ------ | ---------------------------------------------------- | ------ | ---------------------------------------------------- |
| POST   | `/v1/organizations`                                  | —      | `name`, `slug`, `logo?` (caller becomes owner)       |
| GET    | `/v1/organizations`                                  | —      | The caller's organizations                           |
| GET    | `/v1/organizations/:orgId`                           | member |                                                      |
| PATCH  | `/v1/organizations/:orgId`                           | admin  | `name`, `logo?`                                      |
| DELETE | `/v1/organizations/:orgId`                           | owner  |                                                      |
| GET    | `/v1/organizations/:orgId/members`                   | member |                                                      |
| POST   | `/v1/organizations/:orgId/members`                   | admin  | `user_id`, `role`                                    |
| PATCH  | `/v1/organizations/:orgId/members/:userId`           | admin  | `role`                                               |
| DELETE | `/v1/organizations/:orgId/members/:userId`           | admin  |                                                      |
| POST   | `/v1/organizations/:orgId/invitations`               | admin  | `email`, `role?` (`admin`/`member`)                  |
| GET    | `/v1/organizations/:orgId/invitations`               | member |                                                      |
| PATCH  | `/v1/organizations/:orgId/invitations/:invitationId` | admin  | `status` (`accepted`/`rejected`/`revoked`/`expired`) |

# cloudrive

## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `montara-project/cloudrive` (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `CONTEXT-MAP.md` at the root points to per-app `CONTEXT.md` files under `apps/`; system-wide ADRs live in `docs/adr/`, context-scoped ADRs in `apps/<app>/docs/adr/`. See `docs/agents/domain.md`.
